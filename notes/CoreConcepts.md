# Core Concepts to Remember

## Basic Computer Science Stuff

### Data Structures

**Heap:** 
A binary tree in which every parent is smaller (or bigger) than its children, with no ordering between the children. Can be stored as simple array.
To insert a new element, put it at the end of the array, then "bubble it up".
Used when: I want the k smallest or biggest elements

### Algorithms

**Sliding window:**: e.g. you're looking for the smallest substring containing "a", "b", and "c". Or the biggest.
**Greedy algorithms:**: Choose the locally best solution and hope it works out in the long run. Example: making change, start with biggest coin that fits.
