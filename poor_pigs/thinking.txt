For a particular bucket, each pig can be "on" or "off". There are 2^p possible combinations per bucket, which means that 2^p buckets can each have their own unique combination.

Next idea for two turns:

For a particular bucket, each pig can not eat (0), eat on the first turn (1), or eat on the second (2). There are 3^p possible combinations per bucket, which means that 3^p buckets can each have their own unique combination.

The numbers in the tables below are now 0 - 2

    a b c
    -----
p0: 1 2 0

If p0 dies on first turn, it's a. If dies on second turn, it's b. Otherwise, c.


    a b c d
    -------
p0: 1 0 2 0
p1: 0 1 0 0

If p0 dies on first turn, it's a.
If p1 dies on first turn, it's b.
If neither dies on first turn, the death of p0 on second turn will determine outcome.

    a b c d e f g h i
    -----------------
p0: 0 0 0 1 1 1 2 2 2
p1: 0 1 2 0 1 2 0 1 2

Look at the unique combinations.

If bucket is a, neither pig will die
If bucket is b, p0 lives, p1 dies on first turn
If bucket is c, p0 lives, p1 dies on second turn
If bucket is d, p0 dies on first turn, p1 lives
If bucket is e, both pigs die on first turn
If bucket is f, p0 dies on first turn, p1 on second
If bucket is g, p0 dies on second turn, p0 lives
If bucket is h, p0 dies on second turn, p1 on first turn
If bucket is i, p0 dies on second turn, p1 on second turn

Generalized:

If p0 never dies, the bucket is in a - c.
If p0 dies on first turn, the bucket is in d - f
If p0 dies on second turn, the bucket is in g - i

===============================

Arbitrary number of turns:

Number of buckets that can be covered = (T+1) ^ p
b = (T+1) ^ p
p = ln(b) / ln(T+1)

p = math.log(b, T+1)
